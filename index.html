Library Management System

Jan 2025 - April 2025

This Library Management System is a comprehensive web application designed to fully digitize and automate the operations of a library, targeting efficiency and reducing manual paperwork. Built using JSP and Servlets for dynamic web logic, it connects to a MySQL database via JDBC to securely manage all data transactions. The system enforces role-based authority login to protect sensitive functions, provides bulk data import capabilities via Excel/CSV for librarians, and automates critical processes like issuing books, calculating fines, generating PDF receipts, and flagging defaulters who fail to return books after a two-week grace period past the due date.

  • Secure Role-Based Authority Login

    Implements a robust authentication system that distinguishes between Admin/Librarian and Student logins. Librarians have full access to all management features, while students can only view their profile, borrowing history, and status.

  • Bulk Student & Book Data Import via Excel/CSV

    Librarians can add students and books individually or in bulk by uploading Excel (.xlsx) or CSV files. This feature uses a library like Apache POI on the server-side (Servlet) to parse the file, extract the data, and insert it into the MySQL database in batch, saving significant manual entry time.

  • Book Issue & Return Management

    The core transaction system records the issue date, due date (e.g., set to 14 days after issuing), and return date for every book. The Servlet logic calculates the difference between the return date and the due date to determine if a fine is applicable.

  • Automated Fine Calculation and Defaulter List

    The system automatically imposes a fine (e.g., ₹10 per day) if a book is returned after the due date. If a book is not returned within 2 weeks (14 days) past the due date, the student is automatically added to a Defaulter List, which can restrict them from borrowing further books.

  • Dynamic PDF Generation for Receipts & Reports

    Integrates a PDF generation library (like iText or Apache PDFBox) in the backend to create official receipts for issued books, returned books with fine details, and student reports. These PDFs are generated on-the-fly by a Servlet and can be downloaded or printed.

  • Centralized MySQL Database with JDBC Connectivity

    All data—including student details, book inventory, transaction records, fine payments, and the defaulter list—is stored and managed in a structured MySQL database. JDBC is used from the Servlets to perform all CRUD operations securely and efficiently.

It leverages a powerful React frontend to create a dynamic and responsive user interface, integrated with the CodeMirror editor component for essential features like syntax highlighting and language support. The Node.js and Express backend serves as the central server, managing client connections and using Socket.IO to establish a persistent, bidirectional communication channel. This enables the instantaneous broadcast of every code change to all connected users in the same session, creating a seamless, shared editing experience.

  • Real-Time Collaboration Engine

    The core functionality is powered by Socket.IO, which uses WebSockets to instantly synchronize code changes across all clients in a room. When one user types, the changes are immediately reflected on the screens of all other participants.

  • Advanced Editing Interface with CodeMirror
